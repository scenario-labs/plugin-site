# Support

plugin-site is the open-source site tooling of the Scenario plug-ins,
maintained by Scenario.

## Using it

The [README](README.md) explains the action, the command line and every
configuration key; [test/fixtures/sample-plugin](test/fixtures/sample-plugin)
is a complete example.

## Bugs, change requests and questions

Use the [issue chooser](https://github.com/scenario-labs/plugin-site/issues/new/choose).
Search the [existing issues](https://github.com/scenario-labs/plugin-site/issues)
first. A problem with a plug-in itself, or with what its docs say, belongs in
that plug-in's repository.

Public issues are visible to everyone. Never include a token or a signed URL.

## Account, billing and security

Keep these matters out of public issues. Write to
[support@scenario.com](mailto:support@scenario.com) or use in-app support at
[app.scenario.com](https://app.scenario.com). Report security vulnerabilities as
described in [SECURITY.md](SECURITY.md).

## What to expect

Issues are handled on a best-effort basis, without a response-time commitment.
